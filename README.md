# Breadboard to FPGA 8-bit CPU

This repository tracks a long-term computer architecture practice project: building and verifying an educational 8-bit CPU across TTL breadboard logic, Logisim simulation, Verilog RTL, and a Sipeed Tang Nano 9K FPGA.

## Current Status

Planning and preparation. The TTL kit is expected later, so early work focuses on architecture notes, references, Logisim experiments, and Verilog learning.

## Project Path

1. Build and test the TTL breadboard computer module by module.
2. Recreate the same architecture in Logisim.
3. Implement the CPU in synthesizable Verilog with testbenches.
4. Deploy and verify the design on a Tang Nano 9K FPGA.
5. Prepare documentation, photos, test evidence, and a public portfolio version.

## Repository Contents

- `PROJECT_PLAN.md`: full project plan.
- `PROJECT_PLAN.docx`: Word version of the project plan.
- `docs/references.md`: references, datasheets, tutorials, and hardware notes.

## Principle

One module at a time. Test every module. Record every test. Coursework comes first.
